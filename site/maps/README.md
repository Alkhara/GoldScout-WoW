# Zone maps

The game's own world map art for each zone the website has loot areas for,
as `<uiMapID>.webp`. Built by `tools/zone_maps.py` from a WoW Forever install
(see that file for how to export the art with wow.export). The website draws
its loot squares over them; zones without a file here get a plain grid.

The art is © Blizzard Entertainment. It isn't covered by this repository's
